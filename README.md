# nk-coaching-real

Production site for NT Coaching (Vercel project `nk-coaching-real`).

- `coach-app.html` — the coach dashboard (served at `/coach-app.html`). Edit this to change the dashboard.
- `index.html` — redirects `/` to the dashboard.
- `vercel.json` — rewrites the other pages (client check-in, pack, pack order, icons) to their existing pinned deployments.

Push to the production branch to deploy.
